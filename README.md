## 💡 About The Project

This portfolio bridges the gap between algorithmic thinking and modern visual craft. Rather than relying on heavy component frameworks, the site is built on high-performance raw web standards combined with modern animation and graphics engines:
- **Three.js & GLSL Shaders** for an interactive, ambient gold-ridge terrain.
- **Lenis** for smooth momentum-based scroll hijacking.
- **GSAP & ScrollTrigger** for micro-interactions, perspective tilt, and section reveals.
- **Vite** for sub-second build times and a streamlined single-bundle asset pipeline.

---

## ✨ Key Features

- **🪐 Procedural 3D Terrain Field**: An interactive Three.js WebGL background utilizing custom Simplex-noise vertex and fragment shaders with real-time cursor bloom and elevation shifts based on scroll depth.
- **🌊 Fluid Inertial Scrolling**: Momentum-driven scroll mechanics powered by Lenis, synchronizing seamlessly with GSAP's animation ticker.
- **🎭 GSAP Scroll Choreography**: Multi-layer depth parallax on the hero typography, stagger reveals, and scrubbed velocity tickers.
- **💫 Interactive 3D Tilt Cards**: Real-time cursor-tracking perspective tilt applied to skill panels with smooth easing recovery.
- **⚡ Velocity Marquee**: Continuous dual-string ticker that dynamically responds to user scroll velocity.
- **⏱️ Live Local Clock**: Real-time timezone clock (`Asia/Kolkata`) updating automatically in the footer.
- **📦 Clean Asset Pipeline**: Streamlined single CSS and JS bundle with Google Fonts CDN integration, eliminating local font bloat.

## 💻 Getting Started

### Prerequisites
- [Node.js](https://nodejs.org/) (v18.0 or higher recommended)
- [npm](https://www.npmjs.com/)

### Setup & Run

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Biswarup295/Biswarup-Portfolio.git
   cd Biswarup-Portfolio
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start local development server:**
   ```bash
   npm run dev
   ```
   Open `http://localhost:5173` in your browser.

4. **Build production bundle:**
   ```bash
   npm run build
   ```
   Generates optimized, single-bundle distribution files in the `dist/` directory.

5. **Preview production build:**
   ```bash
   npm run preview
   ```
