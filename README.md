## 💡 About the Project
This portfolio serves as a central hub for my work as a B.Tech Computer Science student and software developer. Rather than relying on heavy frontend frameworks, this project is engineered from the ground up using raw web technologies and advanced animation libraries to deliver a buttery-smooth, immersive experience. 

## ✨ Key Features
*   **Cinematic Horizontal Scroll:** A pinned, horizontally scrolling project showcase utilizing dynamic velocity skew for a premium physics-based feel.
*   **Advanced Scroll Animations:** Built with GSAP ScrollTrigger for precise, timeline-based parallax reveals and fade-ups.
*   **Custom Smooth Cursor:** Tracks mouse movement with zero latency using GSAP's optimized `quickTo` function, featuring adaptive blend modes and hover expansions.
*   **Fluid Smooth Scrolling:** Integrated Lenis scroll hijacking for seamless, momentum-based page navigation.
*   **Responsive Editorial Layout:** A split-screen desktop composition that gracefully degrades into a focused, mobile-first experience.
*   **Grayscale Hover Bloom:** CSS-driven image filters that transition project covers from dimmed charcoal to full color on interaction.

## 🛠️ Tech Stack
*   **Markup & Styling:** HTML5, Custom CSS3 (Flexbox, CSS Grid, CSS Variables)
*   **Interactivity:** Vanilla JavaScript (ES6+)
*   **Animation Engine:** [GSAP (GreenSock Animation Platform)](https://greensock.com/gsap/)
*   **Scroll Management:** [Lenis](https://studiofreight.github.io/lenis/) by Studio Freight
*   **Deployment:** Vercel
